# Contributing

Thank you for your interest in TollWire. This project is source-available under the PolyForm Noncommercial License 1.0.0 (see [LICENSE](LICENSE)). It does not accept pull requests from third parties.

## Pull requests

The maintainer does not accept external pull requests. This repository is exported from an internal source, and each publication adds a new snapshot commit without the internal history. Pull requests from third parties are closed with a reference to this file. This is not a judgment of your work. It keeps the copyright of the whole project with a single holder, which the license model needs.

## Issues are welcome

- Bugs and feature requests: open an issue. Name the package (`guardrail-plugin` or `evidence-mcp`), the version and the steps to reproduce.
- Do not include secrets, credentials or personal data in issues.
- You may describe a fix or a patch idea in an issue. The maintainer decides whether and how to implement it.

## Security vulnerabilities

Do **not** open an issue. Report them only as described in [SECURITY.md](SECURITY.md).
